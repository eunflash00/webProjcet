# 하루결 · Routine

외부 라이브러리 없이 HTML, CSS, JavaScript로 만든 매일 루틴 앱입니다.

## 실행

```sh
cd /workspace/webProjcet
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 서버의 8000 포트로 접속합니다. 정적 호스팅에도 그대로 배포할 수 있습니다. 시스템 알림은 HTTPS 또는 localhost 환경과 브라우저 알림 권한이 필요합니다.

## 기본 루틴

- 07:00 아침 독서 10분
- 09:00 알고리즘 문제 1개
- 12:00 매일 영어 10분
- 21:00 운동: 달리기 / 계단 / 스쿼트
- 23:00 글쓰기

운동 항목에서 달리기·계단·스쿼트 중 오늘 한 운동을 선택할 수 있습니다. 선택한 종류는 날짜별로 저장되며 완료 체크는 별도로 할 수 있습니다.

각 루틴의 시간 입력으로 매일 반복되는 알림 시간을 변경할 수 있습니다. 시간은 기기의 현지 시간대를 따릅니다. 완료 체크는 날짜별로 분리되며 최근 100일 기록을 색상 블록으로 볼 수 있습니다. 하루에 루틴을 3개 이상 완료하면 해당 날짜의 블록이 채워집니다. 체크, 시간 설정과 알림 중복 방지 기록은 브라우저 localStorage에 저장됩니다. 다른 기기와 동기화되지 않으며 사이트 데이터를 삭제하면 기록도 사라집니다.

## 알림 범위

상단의 ‘알림 켜기’를 눌러 브라우저 권한을 허용합니다. 앱은 15초마다 현재 분의 루틴을 확인하여 완료하지 않은 루틴을 알립니다. 권한이 없어도 앱 안 메시지는 표시됩니다. 같은 분의 같은 루틴은 반복 통지하지 않습니다.

앱이 열려 있고 브라우저가 실행을 허용하는 동안 동작합니다. 백그라운드 탭, 기기 절전, 앱 종료 시 정시 알림을 보장하지 않으며 지나간 시간의 알림은 재전송하지 않습니다. 일부 모바일 브라우저에서는 시스템 알림 대신 앱 안 메시지만 동작할 수 있습니다. 앱을 닫아도 알림을 받으려면 서버 스케줄러 및 Web Push 연동이 추가로 필요합니다.

## 검증

Node.js 문법 검사와 Chromium 자동화로 기본 루틴, 체크 및 재접속 저장, 날짜별 기록 분리, 시간 저장, 알림 중복 방지, 완료 루틴 알림 제외, 전체 완료, 모바일 가로 넘침과 브라우저 오류를 확인했습니다. 시스템 알림 자체의 OS 전달은 브라우저 및 기기 권한에 따라 별도 확인이 필요합니다.
